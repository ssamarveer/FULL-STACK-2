# Experiment Record

## Title
Interactive Post Scheduling Calendar with Performance Optimization and Testing

## Aim
To design and implement an interactive calendar interface for scheduling and managing posts, optimize rendering performance, and implement testing strategies.

## COs
CO3-BT3, CO4-BT4, CO5-BT5

## Expected Outcome
Functional calendar scheduling, drag-and-drop/resizing, state synchronization, memoized React components, and automated UI tests.

This project is intended as a practical demonstration and includes the full source code and README.
